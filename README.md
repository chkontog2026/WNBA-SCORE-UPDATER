# WNBA Score Updater

Ο server εμφανίζει πρόγραμμα, live scores, βαθμολογία, injury report, box scores, επίσημα WNBA condensed games μετά το `Final` και — προαιρετικά — αποδόσεις νικητή αγώνα από το Pamestoixima.

Τα παιχνίδια αντιστοιχίζονται αυτόματα με το επίσημο WNBA game ID. Μετά τη λήξη εμφανίζεται κουμπί `Condensed game`, το οποίο ανοίγει την επίσημη WNBA σελίδα με `watchCondensedGame=true` ως κανονική καρτέλα. Το League Pass δεν αρχικοποιεί video playback μέσα σε τρίτο `iframe`, ενώ η αναπαραγωγή μπορεί να απαιτεί WNBA ID ή League Pass ανάλογα με τη χώρα και τα δικαιώματα μετάδοσης.

## Ενεργοποίηση αποδόσεων Pamestoixima

Το Pamestoixima δεν διαθέτει δημόσιο επίσημο API. Η ενσωμάτωση χρησιμοποιεί server-side το ανεξάρτητο [Odds-API.io](https://odds-api.io/sportsbooks/pamestoixima), ώστε το API key να μη φτάνει ποτέ στον browser ή στο Android app.

> Για δημόσια προβολή των δεδομένων χρειάζεται κατάλληλη άδεια/συνδρομή. Οι τρέχοντες όροι του παρόχου περιορίζουν την αναδιανομή χωρίς προηγούμενη γραπτή συγκατάθεση· επιβεβαίωσε το συγκεκριμένο use case με τον πάροχο πριν ενεργοποιήσεις το feed στο δημόσιο site.

1. Δημιούργησε API key στο Odds-API.io και ενεργοποίησε το `Pamestoixima` στους διαθέσιμους bookmakers του λογαριασμού.
2. Όρισε το key μόνο στο περιβάλλον του server:

```powershell
$env:ODDS_API_KEY="το-api-key-σου"
node .\wnba-notifier.js
```

Η εφαρμογή εντοπίζει αυτόματα το WNBA league, αντιστοιχίζει τους αγώνες με ομάδα και ώρα έναρξης και εμφανίζει τις δεκαδικές αποδόσεις `Away` / `Home` της αγοράς νικητή αγώνα (`ML`). Αν το feed δεν απαντήσει, διατηρεί προσωρινά τις τελευταίες διαθέσιμες αποδόσεις και η υπόλοιπη εφαρμογή συνεχίζει κανονικά.

Προαιρετικές ρυθμίσεις:

- `ODDS_BOOKMAKER`: όνομα bookmaker στο feed (προεπιλογή `Pamestoixima`).
- `ODDS_REFRESH_MS`: συχνότητα ανανέωσης αποδόσεων σε ms (προεπιλογή 15 λεπτά, ώστε να περιορίζονται τα API requests).
- `ODDS_LOOKAHEAD_DAYS`: πόσες ημέρες μπροστά θα αναζητούνται αποδόσεις (προεπιλογή 7).

Οι αποδόσεις μπορεί να αλλάξουν ή να αποσυρθούν. 21+ • Παίξε Υπεύθυνα.
